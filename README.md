# Wortsuchrätsel Generator

Dies ist eine eigenständige HTML-Anwendung zum Erstellen von Wortsuchrätseln mit folgenden Funktionen:

- Sprache wählbar (Deutsch, Englisch, Französisch)
- Wortliste frei eintragbar
- Schriftart und Schriftgröße einstellbar
- Export als PDF oder SVG
- Optional: Wörter auch rückwärts
- Live-Vorschau im Browser

## Nutzung über GitHub Pages

1. Repository auf GitHub erstellen (z. B. `wortsuch-generator`)
2. Die Datei `index.html` aus diesem Paket hochladen
3. In den Repository-Einstellungen unter **Pages**:
   - Source: `main`
   - Folder: `/ (root)`
4. Link aufrufen: `https://<dein-github-name>.github.io/wortsuch-generator/`
